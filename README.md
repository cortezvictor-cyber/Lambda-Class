# Lambda-Class
Desarrollo de metodos Estaticos 
Este programa usa dos clases con el fin del uso de metodos estaticos para poder resolver las 10 problematicas que se presentan 
1.Multiplicar:Multiplica los elementos de un ArrayList por un factor usando replaceAll().
2. Filtro Selectivo:Elimina palabras que inicien con cierta letra o sean muy cortas usando removeIf().
3. Conversor a Mayúsculas:** Convierte cadenas a mayúsculas utilizando Streams y map().
4. Cuadrados Únicos:Obtiene los cuadrados de los números pares (sin duplicados) en un HashSet.
5. Mapa de Longitudes: Asocia palabras con su número de letras en un HashMap mediante Collectors.toMap().
6. Descuento de Inventario: Aplica e imprime un 10% de descuento a un catálogo de productos usando forEach().
7. Contador de Frecuencias: Cuenta las apariciones de cada palabra usando el método merge().
8. Clasificador de Palabras:Filtra palabras con frecuencia menor a un límite usando entrySet().stream().
9. Deduplicación de Palabras: Convierte una frase en un conjunto de palabras únicas que cumplen con un tamaño mínimo.
10. Tope de Frecuencias:Aplica un límite máximo a los valores de un mapa usando replaceAll().

Para poder ejecutar estos metodos estaticos creamos un main,y si se quiere ejecutar en otro lugar solo lo copias o clonas de aqui y de ahi el metodo main debe realizar la siguiente ejecucion.
